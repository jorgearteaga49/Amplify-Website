# Amplify.build — Version 2.0

Premium single-page website for AMPLIFY Developments LLC.

## Positioning

AMPLIFY is presented as a Texas General Contractor and construction management firm that protects the client's investment through disciplined execution, cost control, project visibility, and accountability.

AMPLIFY is not positioned as:
- A developer
- An architect
- An engineering firm
- An owner's representative

## Included

- Responsive desktop and mobile layout
- Official Amplify logo
- Custom favicon package
- Mobile navigation
- Project-control dashboard mockup
- Project portal mockup
- Scroll animations
- GitHub Pages CNAME for amplify.build

## Files

- `index.html`
- `styles.css`
- `script.js`
- `site.webmanifest`
- `favicon.ico`
- `CNAME`
- `assets/`

## Deployment

Upload all files to the root of the GitHub repository and commit to `main`.
GitHub Pages should remain configured to deploy from `main / (root)`.
